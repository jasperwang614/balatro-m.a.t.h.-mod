# 未证之牌 UNPROVEN

数学主题 Balatro 内容 Mod：猜想、大事件、熵、梗、名数——把整个数学宇宙做进小丑牌。

**v0.3 早期预览**：v1 核心包 28 张 + 补遗先行 8 张 + 数学家线 6 张（共 42 张小丑）全部实装，悖论（消耗牌）先行 3 张，美术为原版占位，数值待整局平衡。欢迎试玩、反馈与投稿美术。

## 安装

1. 安装 [Steamodded (SMODS)](https://github.com/Steamodded/smods) 与 [Lovely](https://github.com/ethangreen-dev/lovely-injector)（依赖 Lovely + SMODS 1.0+，无需 Talisman）。
2. 将本文件夹放入 `%APPDATA%/Balatro/Mods/`。
3. 启动游戏，MODS 菜单应能看到 UNPROVEN。

## 内容（v0.3 · 42 张 Joker + 3 张悖论）

猜想线：冰雹猜想、哥德巴赫猜想、卡塔兰猜想

大事件线：密率、页边太窄 ⭐、怀尔斯、决斗前夜、蛰伏七年、欧拉恒等式、拒领百万、卡拉比-丘流形

熵线：香农熵、二进制、热寂、麦克斯韦妖

梗线：e、73、0.999…=1、1+1=10、由对称性、奇变偶不变、蒙特卡洛方法、二八定律、中心极限定理、注意到……、不妨设

名数线：777、φ·黄金分割、24 点、1729、棋盘麦粒、数字黑洞 6174、零

数学家线（v1.5 先行）：毕达哥拉斯、黎曼、庞加莱、哥德尔、希尔伯特旅馆、菲尔兹奖（数学家计数引擎）

补遗线（v1.5 先行）：G2 in box（鸡兔同笼）、陈景润 1+2、高斯求和

悖论（消耗牌 · Tarot 槽）：熵增、四色定理 1976、蒙提霍尔问题

> 备注：`e` 需要连续 3 手得分递增 + 累计 $27 利息后才会进入商店池；`蛰伏七年` 蛰伏 7 回合后一次性发放 5 张负片传奇小丑 + 8 张负片消耗牌，此后该卡作废；`零` 需要牌组比开局少 6 张才会出现在商店（可当任意点数的万能占位符）。

## 美术占位征集 🎨

如果喜欢这个 Mod，欢迎为卡片投稿原创美术：

- 风格：Balatro 卡面，粗黑描边、平涂、高饱和撞色，**牌面无文字**（文案走本地化）。
- 尺寸：单帧 71×95（1x）/ 142×190（2x）。
- 模板：仓库内 `assets/template/` 提供带 pos 编号的空白网格模板（1x 与 2x）。
- 投稿：画好的帧按 pos 编号提交 PR，或发 Issue 附图层文件；合入后统一启用自定义图集并替换所有占位。
